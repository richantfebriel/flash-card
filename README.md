# Kartu Kata

Flashcard kosakata bahasa Inggris–Indonesia. Web app offline yang bisa dipasang di Home Screen iPhone.

**Buka:** https://richantfebriel.github.io/flash-card/

Cara pasang di iPhone: buka link di Safari → tombol Share → **Add to Home Screen**.

Fitur: tambah kartu (kata, arti, contoh kalimat), latihan flip dengan pengulangan berjarak, kuis pilihan ganda / ketik, suara pengucapan, cadangan & impor JSON.

Data tersimpan di perangkat (localStorage), tidak dikirim ke mana pun.
